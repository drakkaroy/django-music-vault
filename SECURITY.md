# Security Policy

## Supported versions

This is a small, actively-developed personal project — only the latest
commit on `main` is supported. There are no maintained older release
branches.

## Reporting a vulnerability

Please **do not** open a public issue for a security vulnerability.

Preferred: use GitHub's [private vulnerability reporting](../../security/advisories/new)
for this repository (Security tab → "Report a vulnerability").

Alternatively, email drakkaroy@gmail.com with details and, if possible,
steps to reproduce. You should get a response within a few days.
